# Fabriksgolvet

Ett fabriks- och idle-spel i pixelstil som spelas direkt i webbläsaren.

**Spela här:** https://biktorng.github.io/fabriksgolvet/

Bygg startare, rullband och maskiner. Bearbeta råvaror, lås upp ritningar och sälj produkter. Spelet styrs med tangentbord och vänsterklick och sparas automatiskt i webbläsaren.
